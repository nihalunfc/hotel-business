      Where benchmark data can come from (and what we don't do)
      • Sister hotels in the company: the same reports from other properties, shared through the company's own database. Load their exports in step 1 and they appear as extra hotels everywhere in the report.
      • Competitor set (occupancy, ADR, RevPAR): a licensed benchmarking subscription such as STR / CoStar, or a rate-shopping tool (OTA Insight / Lighthouse, RateGain). Export their weekly report as CSV.
      • Google reviews: the Google Business Profile API returns ratings and reviews for the hotels you manage. Competitor ratings are visible publicly in Google Maps; a reputation tool can collect them under licence.
      • Tripadvisor: the Tripadvisor Content API (with an approved key) provides ratings and review counts for listed hotels and restaurants.
      • All-in-one reputation tools: ReviewPro, TrustYou, Revinate or Medallia gather Google, Tripadvisor, Booking.com and Expedia scores for you and your competitors and export them.
      • Public market data: Statistics Canada, Destination Canada and regional tourism boards publish monthly occupancy and visitor numbers for free.
      • What we don't do: scrape sites whose terms forbid it. The production version would connect to the licensed sources above on a daily schedule.
      • File format: one row per number, with the columns date, property, group, source, metric, value. Group is Own, Sister or Competitor; metric is for example Occupancy %, ADR, RevPAR, Rating or Review count.
      How it works, privacy and the production plan

      Matching columns. Each column name is cleaned up and compared with a dictionary of more than 150 names hotel systems use (for example "Business Date", "trans_dt", "Work Date" all mean the date). The tool also reads the values: a column only matches Date if most of its values are dates, an amount only if they are numbers, and so on. Each file can have one column per field; if two columns claim the same field, you are asked to choose.

      Matching names. Hotel and department names are compared by spelling, by initials ("STH" = Summit Tower Hotel, "F&B" = Food & Beverage), by containment ("Summit Tower" inside "Summit Tower Hotel") and by a hotel-industry list of department names.

      Report. Profit = revenue − expense − loss. Labour cost counts as expense. Charts by hour use only the rows that have a time. Week = Monday to Sunday.

      Privacy. Files are read and stored only in this browser (IndexedDB), never uploaded. Saved matching rules and settings stay in this browser's local storage. Each Reset button clears its own part.

      Production plan. This is a demo. The production version would pick up the daily exports automatically (SFTP or the systems' APIs), keep every day in a database for deeper analysis, run the same matching rules on a schedule and email the daily flash report to each manager before their morning meeting, with sign-in and per-hotel access.
