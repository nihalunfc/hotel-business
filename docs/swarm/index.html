What the swarm is

Every agent (a battery, a drone) runs the same small network on its own local view and picks its own action. All agents go through the network in one batched pass, so 10 agents or 1,000 use the same model. Results are measured on data the swarm never trained on, against simple hand-written rules.

One model, any swarm size

A model trained with 10 batteries or 6 drones runs unchanged at 10, 100 and 1,000 agents. The battery fleet stays 1 GW; the forest grows to keep the same area per drone, with one launch pad. Result is peak cut (MW) for energy and forest saved (%) for wildfire.
