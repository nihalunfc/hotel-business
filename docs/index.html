How it is built

One pipeline produces every number on this site. It can be rebuilt from scratch with one command: python analytics/build.py

Sample dataBooking requests replayed against room inventory, so sell-outs, denials and cancellations behave realistically.
SQL warehouseStar schema: hotel, date, segment and channel dimensions; booking, stay-night and denied-night facts.
Quality checksTen checks, including revenue tie-out between grains, must pass before anything is published.
AnalyticsBooking pace, pickup forecast with back-test, unconstrained demand, demand tiers, schedule optimization.
This siteStatic pages reading exported JSON, plus Excel downloads with live formulas.

About this portfolio

I built this to show how I would approach business intelligence in hospitality: start from the decisions people make every day, use the data the hotel already collects, check that every number ties back to its source, and present it so anyone can act on it.

The proposals, analysis approach and direction are my own. AI tools were used for research, drafting and coding support; they are credited in the repository README. No employer data is used anywhere.
